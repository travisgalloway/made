# Test plan

Date: 2026-10-11
Scope: macos/ (Swift package, test target MadeCoreTests)
Audit run: 20261011-195134

The plan covers 154 capabilities. The MadeCoreTests target holds 33 Swift Testing files and one shared support file, with 342 tests. Every file except `LayeringTests.swift`, which reads source files only, imports MadeCore. The audit did not run `swift test`, so pass and fail status is unobserved.

Of the 154 capabilities, 102 have at least one unit or integration reference, and the 6 Deprecated rows are among them. Another 40 Shipped or In progress capabilities have no reference of any kind. The remaining 12 are claimed-only capabilities, which need no test until built.

The audit found `KernelClientTests.testRapidRequestsConflateToLatestValue` flaky and a race in `KernelClient.executePending` (DSN-efe60d18). #90 fixed both. The test now enqueues requests in a fixed order, and `testStaleDebounceDoesNotStrandNewerRequest` covers the race.

Two capabilities have a test-only gap and no ticket: AGENT-5 and VIEW-22. Their rows in Table 2 name the gap.

Table 1 gives the class decisions. Table 2 gives the per-capability coverage.
