# Feature matrix

Date: 2026-10-11
Scope: macos/ (Swift 6 package, targets MadeCore and MadeApp)
Audit run: 20261011-195134

Table 1 lists 158 capabilities with their implementation status. The matrix shows 103 Shipped, 39 In progress, 11 Planned, and 5 Deprecated rows.

Cell values are done, none, or n/a. A cell reads n/a where the layer does not apply to the capability.

- UI is done where a person can reach the capability through a window control or a menu item that has an action.
- API is done where an MCP tool, JSON-RPC method, or public Swift API exposes the capability.
- Data is done where the capability has an in-memory model or cache. Native document persistence is provided by `.made` directory packages (see Persistence note below).
- Contract is n/a on every row because the repository has no docs/contracts/ directory.
- Status is Shipped only where code is reachable through its entry point. Rows with a stub, no caller, or a stated failure are In progress. Rows with no producer code are Planned.
- Status is Deprecated where an earlier row's producer code no longer exists. The row names where the capability went.
- Issue holds the GitHub issue number that tracks the capability. A blank cell has no tracking issue.
- KERN-9 is Shipped. The conflation race (finding DSN-efe60d18) was fixed under #90.
- VIEW-1 is Shipped. Metal unavailable state handling (finding UX-661e2517) was fixed under #108.
- VIEW-28 is Shipped. Antialiased B-rep boundary edge rendering with quad ribbons and GPU-evaluated dynamic silhouettes on curved surfaces with a viewport edge visibility toggle was implemented under #382 (BL-VPT-04).
- VIEW-29 is Shipped. Five viewport display modes (Shaded with Edges, Shaded, Wireframe, Hidden Line Removed, Hidden Lines Visible) across core render types, Metal shaders and depth states, WorkspaceModel state and UserDefaults persistence (`com.made.display.mode`), and UI controls (ViewportCanvasView, MadeCommands, SettingsView) were implemented under #383 (BL-VPT-05).
- INPUT-8 is Shipped. Orbit, pan, and zoom navigation with mouse and trackpad was implemented under #87, and cursor-centered orbit (geometry, selection, ground plane precedence) and cursor-centered zoom (perspective and orthographic) under #385.
- INPUT-6, INPUT-7, and INPUT-10 are Shipped. Viewport drag snapping to vertices, edges, and ground grid was implemented under #88.
- INPUT-9 is Shipped. Viewport ray picking against candidate mesh bounds and selection state in DocumentModel was implemented under #69, and sub-element picking (faces, edges, vertices with GPU offscreen pass, depth bias precedence vertex > edge > face, and CPU raycast fallback) under #202 (BL-SEL-02).
- DOC-8 is Shipped. Interactive viewport gizmo manipulation (translation arrows, rotation rings, and scale cubes with two-physics parameter conversion) with on-demand invalidation and single release commit was implemented under #71 (Phase 4.19) and #72 (Phase 4.20).
- DOC-16 is Shipped. Document model undo/redo registration for parameter, transform, add, and remove edits with Edit menu commands (⌘Z / ⇧⌘Z), selective re-tessellation, zero-kernel transform updates, and continuous slider drag coalescing was implemented under #39.
- DOC-1, DOC-2, DOC-5, and DOC-7 are Shipped with full parametric primitive solid support (Box, Cylinder, Sphere, Cone, Torus, and Wedge) delivered under #314 (BL-PRT-24).
- DOC-10 is Shipped. Canonical typed reference selection (`selection: Set<Reference>`) with automatic pruning across timeline regeneration, rollback, suppression, and deletion, bridged single-solid accessors, and package persistence was implemented under #336 (BL-SEL-03).
- KERN-19 is In progress. STEP import (#82), STEP export (#38), persistent topological naming and deterministic sub-element identification (#152, ADR-D3), and B-Rep tessellation with tolerance control (#201) are delivered.
- WORKSPACE-1 is In progress. The unified multi-pane workspace layout (#118) shipped the toolbar, Navigator, viewport header, Inspector, and console drawer. The Navigator has a Scene tab, and the Inspector features multi-tab inspection with Properties and Document settings tabs (#238, BL-FND-11).
- WORKSPACE-2 is Shipped. The command panel pattern with dual placement (Inspector vs floating HUD) and non-covering HUD placement algorithm was implemented under #315.
- WORKSPACE-3 is Shipped. The native macOS multi-tab Settings window (`Cmd+,`) with General, Units, Navigation, Display, Tolerances, and Shortcuts tabs, UserDefaults persistence, live viewport overlay updates, and CAD navigation presets was implemented under #398.
- WORKSPACE-4 is Shipped. Empty document, empty transcript/log, and no-selection guidance states across 3D viewport, Navigator sidebar, Inspector panel, and console drawer were implemented under #400.
- UI-15 is Shipped. Native document creation, opening, saving, autosave, and in-memory schema versioning and migration using the .made directory package format was implemented under #83 and #237. Per-document units, tolerances, and default material persistence in manifest.json with UserDefaults isolation and undo/redo was implemented under #238 (BL-FND-11). Crash recovery snapshotting for untitled and dirty documents, startup detection, scene restoration, user recovery/discard prompting, and lifecycle cleanup was implemented under #241 (BL-FND-16).
- UI-1, UI-11, UI-12, UI-13, and UI-18 are Deprecated. The Copilot tab and the Geometry menu items were removed in #124.
- AGENT-10, AGENT-11, AGENT-14, AGENT-15, and AGENT-16 are In progress with UI none. `InAppAgentController` has no host view since #124 (decision AGENT-10).

Persistence and simulation note. Native document persistence using the .made directory package format is implemented under #83 and ADR-D7 (via FileDocument and MadePackage). CAE simulation and volume meshing (CalculiX `ccx` and Gmsh out-of-process file deck execution with pure-Swift clean-room fallback in `libs/`) is planned under Phase 6 (#187, #188, #413) and governed by ADR-D5 (#147).
