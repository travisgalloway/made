## Findings

### API-df883446

- Summary: cad_rollback traps on out-of-range index
- Location: macos/Sources/MadeCore/Agent/CADTools.swift:386
- Rule: unvalidated-input
- Severity: high
- Verdict: CONFIRMED
- Evidence: CADTools.swift:381-386: guard let doubleVal = rawIndex.doubleValue, doubleVal.isFinite else {...}; let index = Int(doubleVal). A finite Double outside Int range (for example 1e30) traps in Int(_:), which ends the app process from one tools/call. Fractional values truncate silently. Mutating tool, no range check at the boundary; DocumentModel.setRollbackIndex clamps only after the conversion (DocumentModel.swift:1140).
- Disposition: ticketed as #560
