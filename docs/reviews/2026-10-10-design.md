## Findings

### DSN-efe60d18

- Location: macos/Sources/MadeCore/Kernel/KernelClient.swift:82
- Rule: read-modify-write-race
- Severity: high
- Verdict: CONFIRMED
- Evidence: `executePending` removes the pending job before it compares the job ID. A debounce task that finished its sleep can run after a newer `request()` stores a new job. The stale call then removes the newer job, fails the ID check, and returns. The newer continuation never resumes, so the caller never receives a result. The orchestrator confirmed the interleaving from the code. The failing test `KernelClientTests.testRapidRequestsConflateToLatestValue` (line 54) belongs to the same capability, KERN-9.
- Disposition: ticketed as #90 (KERN-9)

### DSN-20f8bb1f

- Location: macos/Sources/MadeCore/Scene/DocumentModel.swift:91
- Rule: shared-mutable-state
- Severity: high
- Verdict: CONFIRMED
- Evidence: `DocumentModel` is an `@unchecked Sendable` class with a mutable `objects` array and no isolation. `InAppAgentController.sendPrompt` is nonisolated, so tool handlers (CADTools.swift:196-262) mutate the document off the main actor. SwiftUI reads `document.objects` on the main actor (ContentView.swift:76,92). Mutation during a read is a data race. No crash was reproduced.
- Disposition: ticketed as #91
