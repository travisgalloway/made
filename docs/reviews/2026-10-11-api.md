### API-8b67d051

- Location: macos/Sources/MadeCore/Agent/MCPServer.swift:166
- Rule: error-envelope-drift
- Severity: medium
- Verdict: CONFIRMED
- Evidence: Still reproduces (#101 open) on both transports. runStdio reads 65536-byte chunks (MCPServer.swift:166) and the TCP receive uses maximumLength 65536 (:64); each chunk is split on newlines with no carry-over buffer, so a message crossing a chunk boundary yields two -32700 responses (id nil). - Disposition: covered by #101
