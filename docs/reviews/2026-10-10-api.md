## Findings

### API-40fb945b

- Location: macos/Sources/MadeCore/Agent/CADTools.swift:217
- Rule: unvalidated-input
- Severity: high
- Verdict: CONFIRMED
- Evidence: The `cad_set_param` handler never validates `param` or the solid kind. An unknown parameter or an imported solid is a silent no-op that still returns `Updated parameter ...`. The message echoes the unclamped value while the stored value is clamped.
- Disposition: ticketed as #97

### API-be9728ad

- Location: macos/Sources/MadeCore/Agent/CADTools.swift:315
- Rule: unvalidated-input
- Severity: high
- Verdict: CONFIRMED
- Evidence: `solidA` and `solidB` are never checked against `document.objects` before the kernel request. A document mutation follows on kernel success. The handler does not reject `solidA == solidB`.
- Disposition: ticketed as #99

### API-48536121

- Location: macos/Sources/MadeCore/Agent/CADTools.swift:177
- Rule: non-idempotent-mutation
- Severity: high
- Verdict: CONFIRMED
- Evidence: `cad_add_solid` assigns a sequential server-side ID (`box-N`) and accepts no caller-supplied ID or dedup key. A retried `tools/call` after a timeout duplicates the solid.
- Disposition: decision

### API-fff32eae

- Location: macos/Sources/MadeCore/Agent/CADTools.swift:315
- Rule: non-idempotent-mutation
- Severity: high
- Verdict: CONFIRMED
- Evidence: Each `cad_boolean_operation` call generates a fresh `csg-<uuid>` and job ID and appends a new object. A retry produces a second result with no natural unique key.
- Disposition: decision

### API-4d2af3d3

- Location: macos/Sources/MadeCore/Agent/MCPServer.swift:25
- Rule: status-code-misuse
- Severity: medium
- Verdict: CONFIRMED
- Evidence: Any decode failure, including valid JSON with no `method`, returns -32700 with a null ID. JSON-RPC requires -32600 for a structurally invalid request, and the request ID is lost.
- Disposition: ticketed as #95

### API-8d1667e7

- Location: macos/Sources/MadeCore/Agent/MCPServer.swift:67
- Rule: status-code-misuse
- Severity: medium
- Verdict: CONFIRMED
- Evidence: `notifications/initialized` returns a response, and `processMessage` encodes it. A notification has no ID and must receive no response, so the stdio client gets an unsolicited message. The same holds for any request without an ID.
- Disposition: ticketed as #96

### API-6ca88138

- Location: macos/Sources/MadeCore/Agent/CADTools.swift:237
- Rule: unvalidated-input
- Severity: medium
- Verdict: CONFIRMED
- Evidence: `posX`, `posY`, and `posZ` are applied with no range or finiteness check, and values above `Float.max` become infinity. A wrong-typed value is ignored and reported as success. `cad_add_solid` (CADTools.swift:177) silently defaults wrong-typed arguments in the same way.
- Disposition: ticketed as #98

### API-ec83be1c

- Location: macos/Sources/MadeCore/Agent/CADTools.swift:341
- Rule: response-id-mismatch
- Severity: medium
- Verdict: CONFIRMED
- Evidence: The response reports the output ID `csg-<uuid6>`, but `addObject` registers the result as `imported-<seq>`. A caller cannot pass the reported ID to `cad_measure`, `cad_set_transform`, or `cad_remove_solid`.
- Disposition: ticketed as #100

### API-8b67d051

- Location: macos/Sources/MadeCore/Agent/MCPServer.swift:85
- Rule: error-envelope-drift
- Severity: medium
- Verdict: CONFIRMED
- Evidence: The transport reads 65,536-byte chunks and splits on newlines. A message that spans a chunk boundary, or exceeds 64 KB, splits into fragments. Each fragment receives a -32700 error with a null ID.
- Disposition: ticketed as #101
